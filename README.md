## ✦ Domain Routing Architecture (`src/proxy.ts`)

Both domains are powered by this single Next.js 16 application via host-aware routing in `src/proxy.ts`:

1. **`https://portofolio.alfaristudio.my.id`** (or `/portofolio`):
   Serves the **Personal Portfolio of M. Firdaus Alfarizi** (`src/app/[lang]/page.tsx`) featuring Career Journey (2021–2026), Deep-Dive Case Studies, Verified Certifications, and the Creative Archive Gallery.
2. **`https://alfaristudio.my.id`** (or `/studio`):
   Serves the **Alfaristudio Creative Homepage** (`src/app/[lang]/studio/page.tsx`) showcasing our 5 Core Digital Services, Execution Workflow, and Direct WhatsApp Consultation.
